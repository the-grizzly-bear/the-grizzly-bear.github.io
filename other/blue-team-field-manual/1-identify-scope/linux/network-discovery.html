NETWORK DISCOVERY

Net view scan:

smbtree -b
smbtree -D
smbtree -5

View open 5MB shares:

smbclient -L <HOST NAME>
smbstatus

Basic ping scan:

for ip in $(seq 1 254); do ping -c 1 192.168.1.$ip>/dev/null; [ $? -eq 0 ] && echo "192.168.1.$ip UP" || : ; done

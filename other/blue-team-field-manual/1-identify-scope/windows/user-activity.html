USER ACTIVITY

Ref. https://technet.microsoft.com/en­us/sysinternals/psloggedon.aspx

Get users logged on:

C:\> psloggedon \\computername

Script loop scan:

C:\> for /L %i in (1,1,254) do psloggedon
\\192.168.1.%i >> C:\users_output.txt

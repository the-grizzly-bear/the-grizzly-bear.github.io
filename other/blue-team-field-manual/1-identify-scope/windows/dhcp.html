DHCP

Enable DHCP server logging:

C:\> reg add
HKLM\System\CurrentControlSet\Services\DhcpServer\Parameters /v ActivityLogFlag /t REG_DWORD /d 1

Default Location Windows 2003/2008/2012:

C:\> %windir%\System32\Dhcp
